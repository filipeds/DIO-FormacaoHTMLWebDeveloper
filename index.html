Guia das Tags HTML

Desafio de Projeto do Módulo 1 da trilha de HTML da DIO — uma página que explica as tags enquanto as utiliza.

O que é HTML?

O HTML é a linguagem de marcação que estrutura todo o conteúdo da web. Ele não é uma linguagem de programação: não possui variáveis, condicionais ou laços de repetição. Sua função é dizer ao navegador o que cada pedaço de conteúdo significa — se é um título, um parágrafo, uma lista ou um link.

Cada marcação é chamada de tag. Esta página demonstra, na prática, as tags apresentadas nas aulas do módulo, agrupadas por finalidade.

Hierarquia de títulos

O HTML oferece seis níveis de título, de h1 a h6. Eles não servem apenas para deixar o texto maior ou menor: eles descrevem a hierarquia do documento, e é por ela que leitores de tela e mecanismos de busca entendem a organização da página. Os níveis abaixo demonstram essa escala.

Nível 3 — subseção

Divide um assunto tratado dentro de uma seção principal.

Nível 4 — tópico

Recorte mais específico dentro de uma subseção.

Nível 5 — detalhe

Usado em documentos longos, com muitas ramificações.

Nível 6 — observação

O menor nível disponível. Raramente é necessário chegar até aqui.

Boa prática: use apenas um h1 por página e não pule níveis (ir de h2 direto para h4, por exemplo).

Formatação de texto

Dentro de um parágrafo, algumas tags alteram a aparência ou o sentido de trechos específicos:

  • strong — marca um conteúdo de grande importância. O navegador exibe em negrito, mas o valor real está no significado.
  • i — aplica itálico, tradicionalmente usado em termos técnicos, palavras estrangeiras e nomes de obras.
  • u — aplica sublinhado. Deve ser usado com cuidado, porque na web o sublinhado costuma indicar um link.
  • mark — destaca o texto como se fosse feito com um marca-texto, sinalizando relevância no contexto atual.
  • del — indica conteúdo removido do documento. Muito útil para mostrar preços antigos, correções e informações que ficaram desatualizadas.
  • small — reduz o tamanho da fonte, apropriado para notas de rodapé, avisos legais e ressalvas.

Um exemplo combinando as três últimas: a promoção custava R$ 199,00 e agora sai por R$ 149,00. Oferta válida enquanto durar o estoque.

Subscrito e sobrescrito

As tags sub e sup deslocam o texto para baixo ou para cima da linha de base, reduzindo seu tamanho. São indispensáveis em notação científica e matemática.

  • Fórmulas químicas: a água é H2O e o gás carbônico é CO2.
  • Potências: a área de um quadrado é lado2 e o volume de um cubo é aresta3.
  • Ordinais e notas: a 1a edição do curso* começou em 2020.

* Data usada apenas como exemplo de nota de rodapé.

Listas

Lista ordenada

A tag ol cria uma lista numerada, na qual a ordem importa. Cada item é um li. Os passos para criar uma página do zero:

  1. Criar um arquivo com a extensão .html.
  2. Declarar o tipo do documento com <!DOCTYPE html>.
  3. Escrever o head com o título e a codificação de caracteres.
  4. Escrever o body com o conteúdo visível.
  5. Abrir o arquivo no navegador para conferir o resultado.

Lista não ordenada

Já a tag ul gera uma lista com marcadores, para quando a ordem não tem relevância. Algumas tags de bloco muito comuns:

  • Parágrafos de texto
  • Títulos e subtítulos
  • Listas ordenadas e não ordenadas
  • Citações em bloco
  • Linhas divisórias

Listas também podem ser aninhadas: basta colocar um ul ou ol completo dentro de um li.

Citações

A tag blockquote representa um trecho citado de outra fonte. O navegador aplica um recuo à esquerda, deixando claro que aquele texto não é do autor da página:

Esta é para todo mundo. A web que construí é uma ferramenta pública, e ninguém deveria precisar de permissão para publicar nela.

— Tim Berners-Lee, criador da World Wide Web

O atributo cite guarda o endereço da fonte original. Ele não aparece na tela, mas documenta a origem da citação no código.

Tags obsoletas: o caso do font

Nem toda tag continua recomendada. A tag font era a forma antiga de definir cor, tamanho e tipo de letra diretamente no HTML:

Este texto usa a tag font: verde, tamanho 5 e fonte Arial.

Desde o HTML5 ela está em uso recomendado obsoleta. O motivo é uma separação de responsabilidades: o HTML deve cuidar da estrutura do conteúdo, enquanto a aparência fica por conta do CSS. Em projetos novos, use CSS no lugar de font. Ela aparece aqui apenas para fins didáticos, como pede o desafio.

Outras tags que seguiram o mesmo caminho: center, big e strike.
