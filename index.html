Formação HTML Web Developer

Desafios de projeto da trilha de HTML, resolvidos um por módulo. Cada desafio é uma página estática, sem build e sem dependências — basta abrir no navegador.

Desafios

  • Módulo 1

    Guia das tags HTML

    Uma página que explica as tags HTML enquanto as utiliza, organizada por finalidade: títulos, formatação, listas, citações e tags obsoletas.

    Exercita: as 19 tags exigidas pelo desafio, em HTML puro, sem CSS.

  • Módulo 2

    Site da Clínica Vida Plena

    Site de quatro páginas de uma clínica médica fictícia: apresentação, sobre, horários de atendimento e contato.

    Exercita: formulários, tabelas, mídias (video e audio), iframe e estruturação de texto.

  • Módulo 3

    Enciclopédia Aberta

    Artigo de enciclopédia sobre a capivara, com layout de três colunas, tema claro e escuro e índice que acompanha a rolagem.

    Exercita: semântica e acessibilidade — landmarks, skip link, hierarquia de títulos e contraste verificado.

Como abrir

Clone o repositório e abra qualquer index.html no navegador. Não há instalação, build nem servidor. 

git clone https://github.com/filipeds/DIO-FormacaoHTMLWebDeveloper.git

O único recurso que depende de conexão é o mapa do Google Maps na página de contato do Módulo 2. Todo o resto funciona offline.
